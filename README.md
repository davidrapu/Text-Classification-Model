- scikit-learn==1.8.0

- seaborn==0.13.2
- matplotlib==3.10.8
- nltk==3.9.2

---

### How to Run the Code

1. Ensure Python 3.14.0 is installed.
2. Install the required libraries (if not already installed):
```bash
   pip install scikit-learn kagglehub pandas seaborn matplotlib nltk
   ```
3. Open the Jupyter Notebook file (.ipynb) using Jupyter Notebook or JupyterLab.

4. Run all cells in order from top to bottom.

5. The notebook will automatically download the dataset, preprocess the data, train the model, and display evaluation results.


### Notes
- Internet access is required to download the dataset via kagglehub.

- All results reported in the report are generated from the notebook output.
